# 其他 PDK 的适用性检查

记录 Library、Cell、PDK 版本、Virtuoso/Spectre 版本、分析类型、结果集、顶层实例、内部实例路径及原有 opParamExprList。

依次检查：

1. 查询顶层 OP 参数，确认具体缺项。
2. 进入 Subckt 或结果浏览器定位实际 MOS，直接读取目标参数；确认是当前运行的有效数据。
3. 对照生成的 Spectre netlist、内部层次和已有 gm/id 映射，确认相对路径及目标内部器件。
4. 只读检查 Base、当前 User 和有效 CDF，确认缺少映射而非已有覆盖或加载顺序问题。
5. 确认能够在个人 User CDF 建立表达式且保留既有设置，才进入修改流程。

| 不适用或尚不能修改的情况 | 下一步 |
|---|---|
| 底层模型没有目标参数 | 查该模型文档；CDF 不能创造参数 |
| 没有 Subckt 内部 MOS | 检查直接器件的 OP 支持，不套用包装路径 |
| 路径未知、加密或特殊封装 | 获取可核实的接口/文档并确认允许扩展 |
| 已有正确映射但显示失败 | 检查结果选择、保存设置、Annotation 和有效 CDF |
| 当前分析不提供或未保存 OP | 修正分析/保存设置后再判断 |
| 一个封装含多个 MOS | 确认目标物理器件，不能任意选一个内部值代表整体 |
| PDK 升级改变层次或 CDF | 重新审查 Dump 和路径，禁用不兼容的旧覆盖 |

不要把 `.NM0.m1`、库名、Cell 名或 region 数字编码视为跨 PDK 常量。具体 region 编码依据实际模型和模拟器文档解释；无法核实时只报告原始值。
